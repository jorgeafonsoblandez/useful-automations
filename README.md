# 🛠️ Useful Automations Monorepo

A collection of robust, native Python automations to simplify daily tasks.

* **[1. Account Auditor](./1_account_auditor)**: Scans your local IMAP inbox to find which companies hold your data and helps you unsubscribe.
* **[2. Bin Day Notifier](./2_bin_notifier)**: Scrapes your local council website to remind you via Telegram to take the rubbish out.
* **[3. Competitor Radar](./3_competitor_radar)**: Monitors a target URL for changes (price drops, text changes) and sends native Telegram diff alerts.
